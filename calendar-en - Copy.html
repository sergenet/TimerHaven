Calendar

How to use Calendar for focused work — Use the Calendar to reserve time, attach a short checklist, and log session notes so your schedule becomes an actionable plan rather than just events. Create outcome-first blocks (for example: "Draft: project intro — 400 words"), mark them as Busy, and paste a short checklist or links into the event description so you can start immediately.

Practical tips: set a default start time (top right control) so notes get sensible start timestamps; parse short duration hints (e.g., "15–25 minutes") directly in the note text for quick scheduling; export or import ICS templates for recurring focus routines. Logging short notes after a block (one sentence) gives you the data to refine future estimates and measure progress.
