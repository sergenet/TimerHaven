Οικογένειες μονάδων & βασικά

Οι μονάδες ανήκουν σε οικογένειες (μήκος, μάζα, θερμοκρασία, όγκος, χρόνος, επιφάνεια, ενέργεια κ.λπ.). Πάντα μετατρέπετε εντός της ίδιας οικογένειας και επιλέγετε έγκυρους συντελεστές μετατροπής.

  • Μήκος: μέτρο, χιλιόμετρο, μίλι, πόδι, ίντσα.
  • Μάζα / βάρος: κιλό, γραμμάριο, λίβρα, ουγγιά.
  • Όγκος: λίτρο, χιλιοστόλιτρο, γαλόνι (US/UK διαφορές), φλιτζάνι.
  • Θερμοκρασία: Κελσίου, Φαρενάιτ, Κέλβιν (αφινικοί μετασχηματισμοί).

Για εργασίες κρίσιμες στη μηχανική, ανατρέξτε σε εθνικά πρότυπα (NIST, BIPM) για ακριβείς συντελεστές και ορισμούς μονάδων.

Ακρίβεια & κανόνες στρογγυλοποίησης

Καθορίστε την ακρίβεια βάσει του σκοπού. Υπερβολική στρογγυλοποίηση προκαλεί συστηματική μεροληψία· υπερβολική εμφάνιση δεκαδικών μπορεί να υπονοήσει ψευδή ακρίβεια.

Οδηγίες ανά χρήση

  • Καθημερινά / αγορές: 2 δεκαδικά για νομίσματα και ποσότητες που παρουσιάζονται σε τελικούς χρήστες.
  • Μαγείρεμα: στρογγυλέψτε σε λογικές μονάδες (κουταλάκια, γραμμάρια) και παρέχετε επιλογές (μετρικές & imperial).
  • Μηχανική: εμφανίστε σημαντικά ψηφία που ταιριάζουν με την ακρίβεια οργάνου (3–6+ δεκαδικά ανάλογα με τις ανοχές).
  • Ανάλυση δεδομένων: αποθηκεύστε ακατέργαστες τιμές με υψηλή ακρίβεια και στρογγυλεύστε μόνο στο presentation layer.

Πάντα εμφανίστε τη μονάδα μαζί με τον αριθμό και σκεφτείτε να δείχνετε τον συντελεστή μετατροπής ή την ετικέτα «as of» για δυναμικά ποσοστά (π.χ. μετατροπές νομισμάτων).

Θερμοκρασία — ειδικές περιπτώσεις

Οι μετατροπές θερμοκρασίας είναι αφινικές: απαιτούν κλιμάκωση και μετατόπιση. Η μετατροπή μιας απόλυτης θερμοκρασίας διαφέρει από τη μετατροπή μιας μεταβολής θερμοκρασίας.

  • Μετατρέψτε απόλυτες τιμές σωστά:
    • C → F: F = C × 9/5 + 32
    • F → C: C = (F − 32) × 5/9
    • C ↔ K: K = C + 273.15
  • Για αλλαγή θερμοκρασίας (Δ): εφαρμόστε μόνο την κλίμακα (π.χ. πολλαπλασιάστε με 9/5 για ΔC → ΔF) — μην προσθέτετε μετατοπίσεις.

Παράδειγμα λάθους: «Μια αλλαγή 10°C ισούται με 18°F» είναι σωστό· αλλά η μετατροπή 10°C απόλυτης τιμής σε Fahrenheit απαιτεί την προσθήκη 32 μετά τον πολλαπλασιασμό.

Συνηθισμένες συνταγές μετατροπής

Μήκος: μίλια ↔ χιλιόμετρα
  1. Χρησιμοποιήστε συντελεστή: 1 mile = 1.60934 kilometers.
  2. Παράδειγμα: 5 miles × 1.60934 = 8.0467 km → εμφάνιση 8.05 km για τυπική χρήση.
Βάρος: λίβρες ↔ κιλά
  1. Χρησιμοποιήστε συντελεστή: 1 lb = 0.45359237 kg.
  2. Παράδειγμα: 150 lb × 0.45359237 = 68.0389 kg → εμφάνιση 68.04 kg (2 δεκαδικά) ή 68.0 για ιατρική στρογγυλοποίηση ανάλογα με το πλαίσιο.
Όγκος: fluid ounces & cups (US)
  1. 1 US cup = 8 US fluid ounces = 236.588 mL.
  2. Ελέγξτε περιφερειακές διαφορές: UK/Imperial cups και gallons έχουν διαφορετικές τιμές.

Υπολογιστικά φύλλα & παραδείγματα script

Συνηθισμένοι τύποι και μοτίβα script βοηθούν στην αυτοματοποίηση μετατροπών σε κλίμακα.

Παράδειγμα υπολογιστικού φύλλου (Google Sheets / Excel)

Convert miles in A2 to kilometers:
=ROUND(A2 * 1.60934, 2)

Παράδειγμα JavaScript

function convertLength(val, fromFactor, toFactor) {
  // where factors are expressed in meters per unit
  return val * (fromFactor / toFactor);
}
// example: miles->km: milesFactor=1609.34, kmFactor=1000

Αποθηκεύστε τους κανόνες/συντελεστές σε ένα σημείο και επαναχρησιμοποιήστε τους για να αποφύγετε ασυνέπειες ανά φύλλα ή κώδικα.

FAQ

Ε: Γιατί οι μετατροπές imperial vs metric κάποιες φορές δείχνουν «λάθος»;
Α: Εξαιτίας της στρογγυλοποίησης και επιλογών εμφάνισης· επίσης μερικοί δημοσιευμένοι συντελεστές (π.χ. για γαλόνια) διαφέρουν ανά περιοχή (US vs UK). Ελέγξτε ποια έκδοση χρησιμοποιείτε.

Ε: Πώς να εμφανίζω και τις δύο μονάδες για τους χρήστες;
Α: Παρουσιάστε κύρια και δευτερεύουσα μονάδα (π.χ. 68.04 kg (150 lb)) και όπου είναι δυνατόν δείξτε πρώτα τη μονάδα που προτιμά ο χρήστης.
