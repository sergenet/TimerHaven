Familles d'unités & fondamentaux

Les unités appartiennent à des familles (longueur, masse/poids, température, volume, temps, surface, énergie, etc.). Convertissez toujours au sein de la même famille et utilisez des facteurs de conversion autoritaires. Le convertisseur propose des unités courantes et des valeurs par défaut raisonnables pour chaque famille.

  • Longueur : mètre, kilomètre, mile, pied, pouce.
  • Masse / poids : kilogramme, gramme, livre, once.
  • Volume : litre, millilitre, mètre cube, gallons (US/Impérial), tasses.
  • Surface : mètre carré, pied carré, acre, hectare.
  • Température : Celsius, Fahrenheit, Kelvin (transformations affines).
  • Vitesse / Temps / Pression / Énergie / Puissance : unités techniques courantes incluses.
  • Données : modes SI (KB = 1 000) et binaire (KiB = 1 024) — choisissez selon le contexte.
  • Consommation carburant : L/100km ↔ mpg (US/UK) — formules dédiées.
  • Angle & Fréquence : degré/radian et Hz/kHz/MHz.

Pour un usage d'ingénierie critique, référez-vous aux standards (NIST, BIPM) pour des facteurs exacts.

Précision & règles d'arrondi

Choisissez la précision en fonction du besoin. Un arrondi trop fort crée un biais systématique ; trop de précision peut laisser croire à une exactitude illusoire.

Conseils selon le contexte

  • Usage quotidien / achats : 2 décimales pour l'affichage utilisateur.
  • Cuisine : arrondir en unités pratiques (cuillères, grammes) et proposer des alternatives.
  • Ingénierie : afficher les chiffres significatifs correspondant à la précision des instruments (3–6+).
  • Analytique : stocker les valeurs brutes avec haute précision et n'arrondir qu'à la présentation.

Affichez toujours l'unité avec la valeur et pensez à montrer le facteur de conversion ou la date de référence pour des taux dynamiques. Dans l'outil TimerHaven, on peut régler la précision d'affichage et consulter la valeur brute si un arrondi a été appliqué.

Température — cas particuliers

Les conversions de température sont affines : elles combinent une mise à l'échelle et un décalage. La conversion d'une variation de température diffère de la conversion d'une température absolue.

  • Convertir des valeurs absolues :
    • C → F : F = C × 9/5 + 32
    • F → C : C = (F − 32) × 5/9
    • C ↔ K : K = C + 273.15
  • Convertir une différence de température (Δ) : multiplier par le facteur d'échelle (ex. ΔC → ΔF × 9/5) — ne pas appliquer le décalage.

Erreur fréquente : traiter une variation comme une valeur absolue ; par exemple, une variation de 10°C correspond à 18°F (scale only), mais 10°C absolu en Fahrenheit donne 50°F (scale + offset).

Recettes de conversion courantes

Longueur : miles ↔ kilomètres
  1. Facteur : 1 mile = 1.609344 kilomètres.
  2. Exemple : 5 miles × 1.609344 = 8.04672 km → afficher 8.05 km.
Surface : m² ↔ ft²
  1. Facteur : 1 m² = 10.7639104 ft² (1 ft² = 0.09290304 m²).
  2. Exemple : 500 m² × 10.7639104 = 5 381.9552 ft² → afficher 5 382 ft².
Volume : gallons ↔ litres
  1. US gallon → litre : 1 US gallon = 3.785411784 L ; Imperial gallon = 4.54609 L.
  2. Exemple : 2 US gal × 3.785411784 = 7.570823568 L → afficher 7.571 L.
Consommation carburant : L/100km ↔ mpg
  1. Formules correctes (pas un simple multiplicateur) :
    • mpg (US) → L/100km : L/100km = 235.214583 ÷ mpg_US
    • L/100km → mpg (US) : mpg_US = 235.214583 ÷ L/100km
    • mpg (UK) utilise ≈ 282.480936
  2. Exemple : 30 mpg (US) → L/100km = 235.214583 ÷ 30 ≈ 7.8405 L/100km.
Données : KB/MB (SI) vs KiB/MiB (binaire)
  1. Choisissez le mode : SI utilise 1 KB = 1 000 octets ; binaire utilise 1 KiB = 1 024 octets.
  2. Exemple : 1 500 000 octets → SI = 1.5 MB ; binaire ≈ 1.4305 MiB.

Feuilles de calcul & exemples de script

Formules et modèles utiles pour automatiser les conversions à grande échelle.

Exemple tableur (Google Sheets / Excel)

Convertir des miles en A2 en kilomètres :
=ROUND(A2 * 1.609344, 2)

Extrait JavaScript

function convertLength(val, fromFactor, toFactor) {
  // les facteurs sont exprimés en mètres par unité
  return val * (fromFactor / toFactor);
}
// exemple : miles->km : milesFactor=1609.344, kmFactor=1000

Conservez les facteurs canoniques en un seul endroit et réutilisez-les pour éviter les incohérences entre feuilles et code.

FAQ

Q : Pourquoi certaines conversions impérial ↔ métrique semblent « off » ?
A : Parce que les définitions peuvent varier (ex. gallons US vs Imperial), et en raison du choix d'arrondi/présentation. Vérifiez la définition utilisée.

Q : Quel mode données choisir — SI ou binaire ?
A : Utilisez SI (KB = 1000) pour les volumes annoncés décimalement ; utilisez binaire (KiB = 1024) pour la mémoire et contexts techniques. L'outil propose les deux.

Q : Comment gérer une différence de température vs une température absolue ?
A : Voir la section température : les différences se convertissent par mise à l'échelle uniquement (pas de décalage).
