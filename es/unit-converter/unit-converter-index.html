Familias de unidades y fundamentos

Las unidades pertenecen a familias (longitud, masa/peso, temperatura, volumen, tiempo, superficie, energía, etc.). Convierte siempre dentro de la misma familia y utiliza factores de conversión autorizados. El convertidor soporta las siguientes familias y proporciona unidades habituales por defecto.

  • Longitud: metro, kilómetro, milla, pie, pulgada.
  • Masa / peso: kilogramo, gramo, libra, onza.
  • Volumen: litro, mililitro, metro cúbico, galón (US/Imperial), taza.
  • Superficie: metro cuadrado, pie cuadrado, yarda cuadrada, acre, hectárea.
  • Temperatura: Celsius, Fahrenheit, Kelvin (transformaciones afines).
  • Velocidad / Tiempo / Presión / Energía / Potencia: unidades de ingeniería comunes incluidas.
  • Tamaños de datos: SI (KB = 1.000) y binario (KiB = 1.024) — seleccionable según el contexto.
  • Consumo de combustible: L/100km ↔ mpg (US/UK) — fórmulas específicas.
  • Ángulo y frecuencia: grado/radián y Hz/kHz/MHz.

Para trabajo de ingeniería crítico, consulte estándares nacionales (NIST, BIPM) para factores y definiciones exactas.

Precisión y reglas de redondeo

Decida la precisión según el propósito. Un redondeo excesivo introduce sesgos; demasiada precisión puede implicar exactitud falsa.

Guías por contexto

  • Uso diario / compras: 2 decimales suelen ser suficientes.
  • Cocina: redondee a unidades prácticas (cucharaditas, gramos) y ofrezca alternativas métricas e imperiales.
  • Ingeniería: muestre cifras significativas acorde a la precisión del instrumento (36+ decimales según tolerancia).
  • Análisis: almacene valores en alta precisión y redondee sólo en la capa de presentación.

Siempre muestre la unidad junto al número. Considere mostrar el factor de conversión o la marca temporal cuando se trate de tasas dinámicas (p. ej. divisas). En la herramienta de TimerHaven puede ajustar la precisión de visualización y ver el valor bruto si se ha redondeado.

Temperatura — casos especiales

Las conversiones de temperatura son afines: requieren escala y desplazamiento. Convertir un cambio de temperatura difiere de convertir una temperatura absoluta.

  • Convertir valores absolutos:
    • C → F: F = C × 9/5 + 32
    • F → C: C = (F − 32) × 5/9
    • C ↔ K: K = C + 273.15
  • Convertir una diferencia de temperatura (Δ): conviértala sólo por la escala (multiplique por 9/5 para ΔC → ΔF)—no aplique desplazamiento.

Ejemplo de error común: "Un cambio de 10°C es 18°F" es correcto para diferencias; pero convertir 10°C absoluto a Fahrenheit requiere añadir 32 tras la escala.

Recetas comunes de conversión

Longitud: millas ↔ kilómetros
  1. Factor: 1 milla = 1.609344 kilómetros.
  2. Ejemplo: 5 millas × 1.609344 = 8.04672 km → muestre 8.05 km para uso habitual.
Superficie: metros cuadrados ↔ pies cuadrados
  1. Factor: 1 m² = 10.7639104 ft² (1 ft² = 0.09290304 m²).
  2. Ejemplo: 500 m² × 10.7639104 = 5,381.9552 ft² → muestre 5,382 ft².
Volumen: galones ↔ litros
  1. US gallon → litro: 1 US gal = 3.785411784 L; Imperial gallon = 4.54609 L.
  2. Ejemplo: 2 US gal × 3.785411784 = 7.570823568 L → muestre 7.571 L.
Consumo de combustible: L/100km ↔ mpg
  1. Utilice las fórmulas correctas (no un multiplicador simple):
    • mpg (US) → L/100km: L/100km = 235.214583 / mpg_US
    • L/100km → mpg (US): mpg_US = 235.214583 / L/100km
    • mpg (UK) usa constante ≈ 282.480936
  2. Ejemplo: 30 mpg (US) → L/100km = 235.214583 / 30 ≈ 7.8405 L/100km.
Tamaños de datos: KB/MB (SI) vs KiB/MiB (binario)
  1. Elija modo: SI usa 1 KB = 1.000 bytes; binario usa 1 KiB = 1.024 bytes.
  2. Ejemplo: 1.500.000 bytes → SI = 1.5 MB; binario ≈ 1.4305 MiB.

Hojas de cálculo & ejemplos de script

Fórmulas comunes y patrones de script para automatizar conversiones a escala.

Ejemplo de hoja (Google Sheets / Excel)

Convertir millas en A2 a kilómetros:
=ROUND(A2 * 1.609344, 2)

Fragmento JavaScript

function convertLength(val, fromFactor, toFactor) {
  // donde los factores están expresados en metros por unidad
  return val * (fromFactor / toFactor);
}
// Ejemplo: miles->km: milesFactor=1609.344, kmFactor=1000

Almacene factores canónicos en un lugar y reutilícelos para evitar inconsistencias entre hojas y código.

Preguntas frecuentes

P: ¿Por qué algunas conversiones imperial ↔ métrico parecen "incorrectas"—
R: Porque hay diferencias en definiciones (por ejemplo, diferentes valores de galón), además del redondeo y las decisiones de presentación. Verifique siempre la definición usada.

P: ¿Qué modo de datos debo usar — SI o binario?
R: Use SI (KB = 1000) para capacidades que se anuncian en decimal; use binario (KiB = 1024) para tamaños de memoria y contextos técnicos. La herramienta permite cambiar entre modos.

P: ¿Cómo convierto un cambio de temperatura frente a una temperatura absoluta?
R: Consulte la sección de temperatura: las diferencias se convierten sólo por escala, sin aplicar desplazamientos.

Conversor de Unidades

Un conversor de unidades es una herramienta utilizada para cambiar una medida de una unidad a otra sin alterar la cantidad real. Es esencial para la ciencia, la ingeniería y la vida cotidiana.

Historia

Los sistemas de medición modernos evolucionaron a partir de estimaciones de partes del cuerpo (cúbitos) utilizadas en Egipto y Mesopotamia (III milenio a.C.). El sistema métrico, adoptado oficialmente en Francia en 1799, introdujo una lógica decimal universal que transformó el comercio global.
